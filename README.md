# Консольное меню на JavaScript

Rонсольное приложение с выбором одной из трёх задач.

## Функциональность

1. **Билетная касса**. Определение стоимости билета по категории и расчёт количества билетов в пределах заданного бюджета.
2. **Доставка заказа**. Расчёт стоимости доставки в зависимости от расстояния и суммы заказа.
3. **Лестница**. Построение ступеней с пропуском четвёртой и остановкой после десятой.

## Запуск

Для работы необходим установленный Node.js.

```bash
node homework-1.js
```

После запуска программа предлагает выбрать задачу и ввести необходимые данные
